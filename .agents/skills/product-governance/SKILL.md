# Shopping List — Product Governance Skill

## Objectif

Préserver une expérience de liste simple, autonome et composable pendant le développement humain ou multi-agent.

## Sources d'autorité

Lire dans cet ordre :

1. `PRODUCT_PRINCIPLES.md` ;
2. `decisions/REGISTRY.md` ;
3. les PDR applicables ;
4. les issues et prototypes pour le contexte.

## Quand utiliser ce skill

Utiliser ce cadre pour :

- préparer un arbitrage produit ;
- auditer fonctionnellement Shopping List ;
- vérifier qu'une capacité appartient bien à Shopping List plutôt qu'à Home ou CookiGram ;
- contrôler la simplicité de l'UX ;
- évaluer un changement d'arrimage ou d'interopérabilité.

## Méthode d'audit

Pour chaque principe applicable :

1. observer le comportement réel ;
2. le comparer au principe ou à la PDR ;
3. documenter l'écart ;
4. distinguer bug, dette produit et nouvelle décision ;
5. proposer une correction sans inventer de nouvel invariant.

Le résultat doit rendre visibles les divergences entre l'application construite et le produit voulu.
